# Changelog

All notable changes to Sift are documented here.

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Unreleased

### Added

- Clean-slate repository baseline.
- Versioned GitHub-hosted config schema.
- Baseline Composer scripts for Pest, PHPStan, Pint, Rector, and quality.
- Initial CLI bootstrap with JSON `help` and `version` payloads.
- Bundled `sift` skill draft for agent workflows.

### Changed

- Rebuild target is Sift v2 with no v1 compatibility layer.
- Config contract uses `$schema` as the version identifier.

### Removed

- Legacy implementation, tests, docs, and runtime contracts from the active tree.

- First public release.
